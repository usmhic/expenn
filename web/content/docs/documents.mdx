The document vault stores travel-related files you want to keep in one place — passports, visa confirmations, booking itineraries, ID cards, and anything else you might need to pull up at the airport.

## Document types

| Type | What it's for |
|---|---|
| `passport` | Passport scan or photo |
| `visa` | Visa approval or stamp |
| `id_card` | National ID or driving licence |
| `itinerary` | Flight or hotel confirmation |
| `receipt` | Backup receipt storage (outside the expense flow) |
| `other` | Anything else |

## Adding a document

### On web

Go to **Documents → Add document**. You can:
- Give it a name and pick a type
- Assign it to a folder
- Mark it as **sensitive** — sensitive documents are visually flagged in the list

### On mobile

Go to the **Docs** tab. Tap **+** to add a document record. You can link a file URL (e.g. from a cloud storage service) or enter metadata manually.

## Folders

Folders let you organize documents by trip, project, or whatever makes sense to you. Create a folder from **Documents → New folder** (web) or the Docs tab on mobile.

Documents can live in a folder or at the root level — your choice.

## Sensitive flag

Marking a document as **sensitive** adds a lock badge in the list view. It doesn't restrict access on its own (access is already gated by your workspace membership) but it signals to you — and anyone else who might use the same device — that the file contains personal data.

<Callout type="info">
  The document vault stores **metadata and links** — expenn doesn't currently
  provide hosted file storage. Upload receipts directly on expenses; for
  passports and visas, link to a secure cloud location (iCloud, Google Drive,
  Dropbox) and store the reference URL here.
</Callout>
